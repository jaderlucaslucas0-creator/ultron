# Open UltrON — OpenJarvis base

Este projeto incorpora o OpenJarvis como submódulo em `openjarvis/`, fixado no commit base atual.

Fonte: https://github.com/open-jarvis/OpenJarvis

Para baixar também o conteúdo do submódulo:

```bash
git clone --recurse-submodules https://github.com/jaderlucaslucas0-creator/ultron.git
```

Ou, em um clone existente:

```bash
git submodule update --init --recursive
```
